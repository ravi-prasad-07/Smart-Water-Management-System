# Smart Water Management System

A terminal-based **Smart Water Management System** developed in **C** for managing water usage records and calculating water bills for both **Residential** and **Commercial** users. The system includes user registration, login authentication, bill calculation, and data storage using file handling.

## Features

* User Registration
* User Login Authentication
* Water Bill Calculation
* Residential Water Billing
* Commercial Water Billing
* Data Storage Using File Handling
* Simple Terminal-Based User Interface

## Technologies Used

* C Programming Language
* File Handling
* Structures
* Functions
* Conditional Statements
* Loops

## Project Overview

The Smart Water Management System allows users to create an account, log in securely, and calculate water bills based on their water consumption and user type.

The application stores user information in a data file, enabling records to persist between program executions.

## How to Run

### Compile

```bash
gcc swbs.c -o swbs
```

### Execute

**Linux/macOS**

```bash
./swbs
```

**Windows**

```bash
swbs.exe
```

## Sample Workflow

```text
1. Register Account
2. Login
3. Enter Water Consumption Details
4. Select User Type
   - Residential
   - Commercial
5. Calculate Water Bill
6. Save User Data
7. Exit
```
